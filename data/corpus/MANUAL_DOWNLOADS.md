# Corpus: documents to download by hand (ADR 0019)

Generated by `make corpus-manual`. Do not edit by hand. Each section starts with priority sources (T1).

## How to do it

1. Open the link in a browser. Never use scripts, spoofed headers or headless browsers on these hosts.
2. Save the file as `data/corpus/raw/<doc_id>.pdf` (or `.html` / `.htm`). The folder is gitignored; never commit it.
3. **PENDING slot:** pick one document from the index page by the rules below, then fill its entry in `data/corpus/manifest.yaml`.
4. Run `make corpus-import` (it also extracts the date). Rejected scans get a replacement slot here.
5. Share the raw folder on the team drive; others run `make corpus-verify` to prove identical files.

## Placeholder-selection rules

- Relevant to MSME credit, credit guarantees, KFS / loan disclosure, interest rates, payments to MSEs or GST on loan fees.
- Not already in the manifest (import rejects a file whose SHA-256 matches another document).
- One file of at most 20 MB, with a text layer (scans are rejected; there is no OCR).
- CGTMSE replacements: prefer text-layer circulars from 2015 onward.
- **RBI pages (rows marked HTML, listed first):** save the page in the browser as *Web page, HTML only* to
  `data/corpus/raw/<doc_id>.html`. Do not look for the PDF: HTML always has text, so it can never be rejected as a scan.
- In `manifest.yaml` fill `title`, `source_url` (the document itself), `effective_from`, `applies_to` and `jurisdiction`
  (and `superseded_by` for an RBI circular replaced by the 2025 consolidation).

Tiers: T1 RBI Master Directions, RBI FAQs/rates/press releases, CGTMSE replacements, Parliament answers; T2 NCGTC; T3 judgments; T4 state policies; T5 Gazette; T6 others.

## Recipes

Rows marked **Recipe N** have no single link. Follow the recipe for source N, save the document as
`raw/<doc_id>.<pdf|html>`, and fill `title`, `source_url` (the document's own URL), `applies_to` and `jurisdiction`
for that doc_id in `manifest.yaml`.

- **Recipe 2 - RBI circulars superseded by the 2025 consolidation (set superseded_by):** RBI Notifications (https://www.rbi.org.in/Scripts/NotificationUser.aspx): use the year filter for 2015-2025 and open circulars on lending to MSMEs, Key Facts Statement, interest rates on advances / external benchmark, fair practices code, or loans and advances that the 28 Nov 2025 consolidation repealed (the new Master Direction lists them in its repeal annex). Save the circular page as Web page, HTML only; set superseded_by to the matching R-RBI Direction.
- **Recipe 14 - Lok Sabha / Rajya Sabha answers on MSME credit, CGTMSE, TReDS, delayed payments:** sansad.in Questions and Answers (Lok Sabha: https://sansad.in/ls/questions/questions-and-answers ; Rajya Sabha: https://sansad.in/rs/questions/questions-and-answers): filter Ministry = Micro, Small and Medium Enterprises or Finance, sessions 2024-2026, and search the subject for MSME credit, CGTMSE, TReDS, delayed payment, Samadhaan or Udyam. Open each answer and save its PDF; one answer per row.
- **Recipe 15 - Supreme Court and High Court judgments on the MSMED Act:** Start with the MSME Samadhaan list of Supreme Court judgments on delayed payment (https://samadhaan.msme.gov.in/OrderDocument.aspx) and save each linked judgment PDF as its own row. For more, use the Supreme Court judgment search (sci.gov.in, by free text 'MSMED Act' / 'Facilitation Council', years 2015-2026; a person may solve the CAPTCHA, a script may not) and save the official judgment PDF. Legal points only (ADR 0020).
- **Recipe 16 - State MSME/industrial policies - Maharashtra (home) and other states (KR-04 distractors):** Maharashtra (home, IN-MH): the Industries Department site di.maharashtra.gov.in does not respond; find the Maharashtra Industrial Policy 2019 or current MSME policy on an official Maharashtra site (maharashtra.gov.in Government Resolutions, MIDC midc.maharashtra.gov.in) and save the PDF. Karnataka (IN-KA): save the Karnataka Industrial Policy PDF from the Karnataka Commerce and Industries department site. Set jurisdiction accordingly.
