# E6 — Working Capital agent (2026-11-15)

Independent evaluation of Phase 9b (uncommitted at evaluation time; `make check` 1037 passed, 2 skipped).
Method: a scratch harness built a fresh seeded gateway (`create_app`, tmp case.db), and for each of the 15 frozen
cash-flow items (T036–T050) created a case as `demo.preparer`, uploaded the 7 frozen files through
`POST /v1/cases/{id}/files`, and ran onboarding then working capital through the agent routes. It ran twice: model off,
and model on with an **adversarial** FakeLLM whose every reply invents an amount and a rate. Every GO figure was
recomputed **independently** in plain floats from the raw CSV/JSON (own Indian-format parser, own BRD §8.4 formula,
no engine and no gold import), then compared to the API and to gold. Explanation numbers were checked with an
evaluator-side matcher (not the agent's `grounded`).

## 2. Findings

**MUST** — none.

**SHOULD**
1. `agents/working-capital/src/credassure/agents/working_capital/prompts/wc_explain.yaml` — live qwen3:8b keeps model wording only 5/13 because it drops a zero from Indian grouping. Fix: show each amount also as lakh/crore text (e.g. "₹1,10,00,000 (110 lakh)") or ask for lakh figures and allow them in `grounded`; re-measure the acceptance rate.
2. `agent.py:190` — `grounded` checks values, not meaning: a draft saying the need is "higher than the request" passes if the numbers match. Fix: until VER-06, reject comparative words ("higher/lower/more/less than") unless they agree with the sign of `wc.bridge.peak_shortfall_vs_request`, or keep the template for the comparison sentence.
3. Blocker fields are path-qualified (`opening_position.min_cash_buffer`) while gold uses bare names (`min_cash_buffer`). Fix: the Phase 11 harness scorer compares on the last path segment (as `test_wc_items.py` does), or gold is updated in v2.

**NIT**
1. `wc_header_map` (design-detail §2.4.3, S20 header variants) not built; it is optional in PHASE_PROMPTS. Fix: record as deferred in PROGRESS and the agent README.
2. `validators.REQUIRED_OPENING` lists `credit_lines`, but the schema defaults it to `[]`, so it can never be reported missing. Fix: drop it from the list or make it required.
3. `BANNED` (`agent.py:35`) also matches "acceptable"/"significant" and words like "interest". Safe (template), but it lowers the model-wording rate. Fix: retire it with the Critic in 9d.

## 3. Verdict: **READY**

15/15 cash-flow items via the API with the model off and on, independently recomputed to ₹1 (cash table to ₹0); one question
and stage-only resume for both the missing-field and conflicting cases; no explanation number outside the ledger.

Top fixes: (1) improve the `wc_explain` acceptance rate on the 8B model (SHOULD 1); (2) guard comparison direction until
VER-06 (SHOULD 2); (3) score blocker fields by last path segment in the Phase 11 harness (SHOULD 3).
