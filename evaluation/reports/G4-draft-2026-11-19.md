## Why regulatory stops at 13/25 (failure analysis, 12 items)

| Failure | Items | What happened |
|---|---|---|
| Search miss: no gold document in the hybrid top 5 | T001, T002, T004, T005, T006, T007, T013 | The model never sees the gold document; circulars and other scheme pages outrank it |
| Correct answer, non-gold citation | T016, T019 (T011 on some runs) | Gold is in the top 5, but the model cites an FAQ, a parliamentary answer or a related Direction stating the same fact; the strict scorer accepts only the gold document |
| Abstained | T009 (top reranker score 0.129, below the 0.4066 gate), T010 (correctly blocked: old ₹250 crore limit), T011 (on some runs) | |

On the retrieval dev split (20 queries, never the frozen sets) a relevant document reaches the top 5 for **17/20**, but
answers cite one for only **10/20**: the main loss is the 8B model turning good retrieval into a correctly cited answer.

to the remaining regulatory points.

## Fixes made during G4 (evaluation integrity)

- **Context length:** the first live run was on Ollama's default 2048-token context, which cut prompts; all reported
  runs use 8192 (`ollama ps`). Setup guide and troubleshooting updated.
- **Response cache:** ablations A1/A4 first replayed replies cached under the 2048 context (cache key has no context
  length). Scored runs now never read the cache (PR #18); A1/A4/A5 re-run fresh with identical scores.
- **Harness tokens:** sign-in refreshed every 20 minutes so long runs no longer fail with 401 (PR #16).
- **Failure labels:** `no_citation` / `wrong_citation` / `invented_citation` now say what happened (PR #18).
- **Critic false positives:** counts written in words ("forty-five days") and approval-matrix wording grounded in a
  cited internal policy (PR #17). Predictions and lender sentences stay blocked.
- **Corpus check:** T003's cited CGTMSE Co-Lending scheme document is not superseded (its own text); no data change.
