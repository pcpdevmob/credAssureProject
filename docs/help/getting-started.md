# Getting started

CredAssure prepares and reviews a working-capital loan proposal. The language model reads, explains and drafts; code
calculates, routes and gates; a person approves. Every figure you see comes from the fact ledger and can be opened to
show its source.

## Sign in
Use the username and password your administrator gave you. If your account asks for it, enter the 6-digit code from
your authenticator app, or one of your backup codes. A new account first changes its password and sets up the
authenticator. While you work, your session renews itself; it ends 4 hours after you signed in, or after 30 minutes without
activity. Then sign in again.

## Roles
| Role | What you do |
|---|---|
| Preparer | Create cases, upload files, run the stages, ask Ask CredAssure |
| Director, Finance | Decide proposals below ₹1,50,00,000 |
| VP, Finance | Decide proposals above ₹1,50,00,000 and held boundary cases |
| Evaluator | Read the audit log, the safety events and the evaluation scorecard |

The menu shows only the screens for your role. The server checks every action again, so a hidden screen is not the
only protection.

## Create a case
Preparers open **New case**, enter the MSME, order and requested amount, then upload the case files on **Documents**.
The step-by-step guide is in [preparer.md](preparer.md).
