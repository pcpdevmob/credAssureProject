# Glossary

| Term | Meaning |
|---|---|
| APR | Annual percentage rate: the yearly cost of a loan including interest and all charges |
| Bridge | The steps from the requested amount to the calculated funding need |
| CGTMSE | Credit Guarantee Fund Trust for Micro and Small Enterprises |
| Fact ledger | The store of validated figures and their sources; the only place figures come from |
| Gate | A decision between stages: GO, NO_GO, NEEDS_INPUT or ERROR, made by code |
| Guardrail | A check on input, retrieval, tools or output that can block, redact or flag |
| Hash chain | Each audit event includes the hash of the one before, so a change or removal shows |
| KFS | Key Facts Statement, the RBI-mandated loan cost disclosure |
| Peak shortfall | The lowest cumulative cash position below zero across the forecast weeks |
| Repayment fit | Whether an offer's instalments keep cash above the minimum buffer |
| Verification Critic | The checker that blocks unsupported figures and citations |
