`path::test_name`. `tests/test_owasp_asi_mapping.py` fails if a row is missing or names a test that
no longer exists. Numbering follows the 2026 lists. ADR 0002 keeps the 2025 numbering for its STRIDE rows.

the control is removed, and five controls were reworded to what is tested (LLM04, LLM10, ASI03, ASI05, ASI09). Rows ASI06
and ASI07 now cite the import rules they rest on. A reviewer who does not own the security module still confirms each row (H11).
